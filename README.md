# 魔法骑士：单人征服

一个本地运行的《Mage Knight》单人征服规则原型。玩家可选择仅使用基础版组件，或混入当前已录入的 Ultimate Edition 扩展组件；游戏保留牌组构筑、英雄技能、昼夜地形、魔力源、地点互动、盟军、四阶段战斗、虚拟玩家计时与最终计分。

这是非官方、非商业的个人学习项目，不包含原版插画、卡图或完整卡文。

## Prerequisites

- Node.js `>=22.13.0`

## 本地启动

```bash
npm install
npm run dev
```

终端会显示本地地址，通常为 `http://localhost:3000`。用浏览器打开即可游玩。游戏进度会自动保存到浏览器本地存储。

官方资料采用许可优先的本地收集流程：`npm run assets:official` 只归档官网明确提供下载的规则文档，并把没有书面再利用许可的宣传图隔离为元数据候选，不会自动接入 UI。详细边界见 [OFFICIAL_ASSETS.md](./OFFICIAL_ASSETS.md)。

## 已实现

- 四名基础英雄，以及可选的狼鹰、克朗、布雷瓦拉三名扩展英雄；三档城市难度
- 七套英雄专属技能，并在偶数等级触发二选一成长
- 三昼三夜、两城目标与战术选择
- 开局公开区域预览与可见重抽；未翻开的板块牌库保持未知，确认种子会原样用于正式游戏
- 基础游戏 A/B 起始板块、11 块乡野板块与 8 块核心板块的固定七格地形/地点模板
- 单人征服按规则随机选取 7 块乡野、2 块非城市核心和 2 块城市核心，探索时整块翻开并按固定方向拼接
- 可复现的板块洗牌种子、规则随机/教学序列双模式、楔形与开放轮廓、湖泊/山脉阻挡和完整昼夜地形费用
- 16 张起始牌组、强化效果、横置、魔力水晶和魔力源
- 村庄、修道院、要塞、法师塔、矿场、林地、遗迹、怪物巢穴、地下城、古墓、繁殖地、迷宫、大迷宫、难民营、扩展场景地点、沃尔卡雷营地与城市
- 地图建筑名称、地点效果说明和可执行行动指引
- 开局及游戏中随时可打开的百科界面，收录规则、全部当前卡牌、敌人、地点、地形、盟军、英雄技能和固定地图板块，并支持分类搜索
- 地图优先的桌面布局：地点详情仅在悬浮/键盘聚焦六角格时出现，资源池收纳为右下角 76–88px 半透明单列窄轨，地图延伸到窄轨下方；可用按钮或 F 键进入地图专注模式
- 底部悬浮手牌架：桌面端默认只露出牌头，悬浮或键盘聚焦时完整展开；触屏端保留完整卡牌与横向滚动
- 始终公开的盟军、进阶行动和法术供应区，并显示地点与资源限制原因
- 修道院进阶行动供应、每轮盟军刷新和差异化治疗费用
- 物理、火焰、寒冰与冷热火攻击/格挡，抗性折算、双重防御工事、分别/合并攻击组与防卫分配
- 迅捷、残暴、中毒、麻痹、召唤、刺杀、防卫、笨重、飘忽与奥术免疫等敌人特性逐阶段结算
- 盟军多能力选择、颜色魔力/水晶支付、临时魔力、盟军抗性与中毒双伤势
- 虚拟玩家计时、回合终局、自动存档与结算评分
- 原创英雄头像、八类敌人立绘、十二种等距微缩建筑模型、六类地形纹理，以及 26 张行动/法术牌插画
- 真正的 WebGL 3D 微缩地图：七名英雄、130 枚敌人、30 种盟军、10 类地形和 21 类建筑均有立体网格；模型图鉴可分类搜索、放大和旋转查看
- 全组件精细微缩模型：198 个英雄/敌人/盟军/地形/地点身份均接入授权或原创 GLB；带近/远两档、离线材质、原模型对比与来源署名。同族、职业与元素色系会共享身体网格，不表示 198 个独立写实雕刻

视觉资产位于 `public/assets/`，采用图集裁切方式复用，未使用原版游戏插画或组件扫描图。

3D 地图默认启用“精细模型＋清晰”，模型与全部纹理本地加载，不依赖在线服务；加载失败仍保留可操作的简约造型。完整来源、共享关系、限制和再生成步骤见 [REALISTIC_MODELS.md](./REALISTIC_MODELS.md)。右下角可切换“精细模型／简约”，图鉴可分类查看和对比所有组件。地图支持左键/单指平移、滚轮/双指缩放、右键旋转、方向键平移、R 旋转、T 俯仰及 Home 复位；“键盘选格”提供等效点选。顶部可切换回 2D，不支持 WebGL 2 时自动回退。画质“清晰”按原生像素密度渲染（最高 3 倍、600 万像素），加载移动版；“超清”增加完整模型与距离 LOD；“省电”使用简约模型。地图文字保持固定清晰字号。Android 保留 30fps 上限，关闭实时阴影；闲置模型缓存限制为 4 份，实际性能仍需真机验收。

## 当前范围

地图按实体板块工作：每块大板上的七格地形、地点、矿色与朝向固定，种子只决定选中了哪些板块及其牌库顺序。开局预览只显示规则允许公开的起始区域；走到板块边缘后花费 2 移动翻开整块新板块。当前数据池含 119 张不同卡牌、30 种不同盟军、77 项英雄技能、130 枚敌人和 15 枚遗迹标记。扩展组件可在开局关闭；已录入的单人规则覆盖登记表当前为 0 缺口，不包含多人对抗或所有官方剧情场景的独立脚本。

完整的规则交叉核对与已知简化见 [RULES_AUDIT.md](./RULES_AUDIT.md)；持续回归基线、逐组件测试合同和实时规则缺口见 [TESTING.md](./TESTING.md)。

## Git 开发约定

从 2026-10-16 开始，当前游戏状态作为 Git 基线纳入本地版本控制。更早的开发过程不补造提交历史。

暂时只在 `main` 主分支开发，不创建功能分支或额外工作树。每次交付按逻辑拆成多笔提交，记录实现、回归用例和配套文档；不使用空提交凑数。完整协作要求见 [AGENTS.md](./AGENTS.md)。

源码、测试、依赖锁文件、Android 工程源文件和实际使用的模型/署名都被追踪；依赖、缓存、临时下载资料、APK、构建产物及本机配置不进入仓库。Git 仅保存在本机，未配置远程仓库或自动推送。

```bash
git status
git log --oneline -10
git show <提交哈希>
```

后续大改动继续执行 `npm run test:full`；移动端改动另外生成并校验 APK。提交前检查暂存差异，交付时列出提交哈希与验证结果。
